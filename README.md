# ningkeling-skills

个人可复用 AI Skills 与实践方法

## 画风DNA v1.1

从一张或多张参考图提炼想延续的画风和视觉感受，再结合新主题写出生图提示词。[查看 Skill](.agents/skills/art-style-dna/SKILL.md)

## 在 Codex 中使用

1. 克隆本仓库，并在 Codex 中打开仓库目录。
2. 附上一张或多张参考图，输入 `$art-style-dna`，说明你想画的内容和需要延续的感觉。
3. 把得到的提示词与参考图一起交给支持参考图的生图模型。

在其他项目使用时，把本仓库的 `.agents/skills/art-style-dna` 目录复制到对应项目的 `.agents/skills/` 下，再开启会话。
